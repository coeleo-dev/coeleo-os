Coeleo OS

A from-scratch x86_64 operating system, written in Rust.

Not Linux, not Windows, not Redox, not an RTOS. The kernel, the syscall ABI, the design system and the userspace are built in this repository — from boot to desktop.

Assembled from focused components — not a whole OS

Coeleo OS selectively reuses focused components rather than embedding a whole operating system. Everything else is code you can read here.

  • LimineBootloader (UEFI and BIOS)
  • FlantermTerminal emulation
  • smoltcpTCP/IP stack
  • fatfsFAT32 filesystem
  • rustlsTLS 1.2 / 1.3

The rest — physical and virtual memory, the heap, the preemptive scheduler, the syscall ABI, the software compositor, the design system, the shell, the UI toolkit, the file manager, the installer and the package manager — is implemented in this repository.

What is implemented

Boot to a desktop and a working prompt: its own memory, scheduler, syscall ABI, filesystem, drivers and compositor, with a userspace on top. One core, a software framebuffer and at most eight processes at once.

01 Kernel and hardware

Boot and CPU foundation

Limine on UEFI and legacy BIOS, GDT, IDT, LAPIC timer and interrupt routing, ACPI and a civil RTC clock. Context switching lives in naked assembly in one file.

Memory management

A physical frame bitmap (PMM), 4-level paging (VMM) with strict user/kernel address-space isolation, and a kernel heap allocator.

Preemptive scheduler

Round-robin driven by LAPIC timer interrupts, with a PCB table capped at 8 concurrent processes, zombie reaping and clean resource teardown.

Syscall layer

27 syscalls reached through libcoeleo, covering processes, files, pipes, the network, time, window surfaces, system info and the clipboard.

FAT32 and storage

FAT32 with cluster allocation, long filenames, traversal, read, write, truncate and sync. Disk backends: VirtIO-blk, SATA AHCI with GPT partitions, and USB Mass Storage.

Networking

smoltcp over virtio-net or Intel e1000e — one PHY, picked at boot. Static IPv4 or DHCP, ARP, ICMP echo, DNS A records, an HTTP client and TLS 1.2/1.3.

Input drivers

PS/2 keyboard with full scancode translation and key event dispatch; PS/2 and USB HID mice over UHCI and xHCI controllers.

02 Desktop

Software 2D compositor

Pure CPU linear-framebuffer rendering with dirty-rect clipping and selective damage updates, so only what changed is repainted. No hardware acceleration.

One shared design system

Kernel chrome and Ring 3 applications paint from the same palette and metrics (coeleo-theme), with SDF hairline borders, anti-aliased corners and layered shadows.

Window management

Floating windows with dragging, 8-direction edge resize, minimise / maximise / close controls, title elision and a glowing accent border on the focused window.

Panel and launcher

A floating pill or full-width panel with a live clock and network indicator, plus KRunner (Alt+Space) — a modal overlay with fuzzy search and keyboard navigation.

Graphical file manager

An embedded dual-pane explorer with breadcrumb pills, a Places and Devices sidebar, per-file icons and keyboard navigation.

Clipboard and notifications

A kernel-level global clipboard behind SYS_CLIPBOARD, shared by the terminal, the shell and GUI apps. Floating rounded toasts report background work, copies and alerts.

Wallpaper and settings

Full-screen desktop with solid colours or decoded JPEG/PNG wallpapers, with preferences persisted to the disk across reboots.

03 Shell and terminal

Virtual terminal

A Flanterm terminal embedded in the window, with a 16-colour ANSI palette harmonised with the Slate theme, cursor positioning, bold text and clean blits.

Readline-class shell

Line editing with Home/End, word jumps, kill and transpose; a 128-entry history ring, Ctrl+R reverse search, Tab completion, aliases, semicolons, pipes and redirects.

Command catalog

52 builtins across files and directories, text processing (grep, wc, head, tail), processes and memory, storage inspection, packages, networking and power.

Errors that help

Semantically styled error:, warning:, tip: and usage: prefixes, target-specific descriptions, and a Levenshtein suggestion engine that asks “did you mean…?”.

04 Applications and packages

Signed packages

Ed25519 signatures and SHA-256 integrity verification for .coe payloads, fetched over plaintext HTTP or TLS and installed from disk or the network.

Text editor

edit, a TUI editor on the virtual terminal, with save and quit shortcuts.

OS installer

A graphical and CLI installer that deploys the system onto a GPT-partitioned AHCI or USB disk.

Immediate-mode UI toolkit

libcoeleoui gives Ring 3 apps the same widget language as the desktop; the widgets binary is a live demo of it.

Architecture

One kernel crate, folders by domain. Programmes are static Ring 3 ELFs on top, and a syscall ABI is the only thing that crosses the line.

  Ring 3 - userspace                Ring 0 - kernel
  --------------------------------  --------------------------------
   static no_std ELFs               one crate
   entry at _start                  folders by domain, not crates
   no libc, no dynamic linking      no userspace code linked in

                |    syscalls (27)    |

Build and run

Requires a Linux host with QEMU. Rust nightly is pinned by the toolchain file.

Prerequisites (Ubuntu / Debian)

sudo apt install make build-essential xorriso \
  qemu-system-x86 python3 mtools gdisk

Build, then boot

# Kernel ISO, userspace ELFs and test packages
make all

# UEFI boot: virtio-blk, virtio-net, USB mouse
make run
Other run targets 
make run-ahci    # SATA/AHCI boot disk with a GPT partition
make run-e1000e  # Intel e1000e NIC instead of virtio-net
make run-usb     # xHCI with USB Mass Storage
make run-bios    # boot the ISO through legacy BIOS instead of UEFI
make run-hdd     # boot from a GPT hard-disk image (UEFI)
Automated tests

Integration suites run QEMU headless and assert against the serial log — including TLS and package-signature verification.

Roadmap

Work here is phase-gated: one written spec, then the code, then that phase's gate. The order below is what unblocks a person at a real machine, not what is easiest to demo.

Shipping today — from boot to a desktop: its own physical and virtual memory, preemptive scheduler, syscall ABI, compositor, shell, editor, installer, package manager and TLS. On one core, with at most eight processes at once, on FAT32.

Next

Leave the PS/2 desk

Drivers that stop the machine depending on a 1990s port and a legacy disk controller.

  • 27
    NVMe

    The typical internal SSD is not AHCI. This brings the same FAT tree up on a modern drive.

  • 28
    USB-Ethernet

    Wired networking with no PCI NIC, so a machine with a dongle is not offline.

Then

Session depth

What turns a working prompt into a session you can rely on.

  • 29
    Anonymous mmap and copy IPC

    Memory is reached through the library's allocation API today. A general mapping interface is what unlocks the rest of this band.

  • 30
    Userspace sockets

    The TCP/IP stack lives in the kernel today. Sockets expose TCP to Ring 3 without moving where the stack runs.

  • 31
    HTML subset viewer

    Render real documents on the OS itself, starting from a defined subset of HTML and CSS.

  • 32
    User model

    Multi-user sessions and privilege levels, built as a Coeleo-native capability. There are no users or privileges to elevate today.

  • 33
    NTP

    Set the clock from the network instead of trusting the RTC alone.

Later

CPU, measured first

One core and a 100 Hz tick already cover the target envelope, so these wait for a measurement that asks for them.

  • 34
    Tickless LAPIC

    Stop paying for a periodic interrupt when nothing is runnable.

  • 35
    Symmetric multiprocessing

    Put every core to work, which means rewriting memory and heap locking end to end.

  • 36
    Threads inside a process

    One thread per process today. Threads need a new PCB, stack and address-space story first.

Long term

Radio, media, laptop

Each of these is a project of its own, and each waits on the band above it.

  • 37
    Wi-Fi

    Firmware blobs and 802.11 are where small systems stall, so this lands once wired networking is solid.

  • 38
    Audio

    No sound device is driven today.

  • 39
    Suspend

    S3 sleep states, built on the ACPI work already landed.

  • 40
    Battery and lid

    Power reporting and lid events for laptop use.

Vision

Beyond the reference machine

The far horizon: the subsystems that turn a working desktop into a general-purpose platform.

  • 41
    Compositor and network in Ring 3

    Move both out of the kernel, behind inter-process communication.

  • 42
    Declarative UI toolkit

    A higher-level toolkit for building applications, alongside the immediate-mode one.

  • 43
    Tiling window management

    A keyboard-driven tiling layout offered next to the floating desktop.

  • 44
    EXT4 read and write

    A second filesystem, lifting the FAT32 per-file ceiling and adding crash safety.

  • 45
    POSIX ABI, relibc and shared objects

    Dynamic linking and a familiar ABI so software ported from elsewhere can load.

  • 46
    IPv6

    Next-generation addressing alongside the IPv4 stack.

  • 47
    3D GPU acceleration

    Hardware-accelerated rendering and compute beyond the software framebuffer.

  • 48
    5-level paging and IOMMU

    A wider address space, plus DMA isolation for device drivers.

  • 49
    HTML and CSS engine

    Extend the same engine toward full document layout and richer web content.
